# 档案与地图动效

资料场景以深色底、立绘、放大英文标识和少量黄／青强调组织信息；地图场景保留浅色六边形地形与技术标记。视觉参考明日方舟官方资料及公开宣传画面，动效为本项目编写的交互演绎，不分发或宣称逐帧复刻官方影片、音乐或动画资产。

## 档案界面

| 行为             | 当前节奏                                     | 交互规则                                             |
| ---------------- | -------------------------------------------- | ---------------------------------------------------- |
| 按钮反馈         | 颜色、背景与描边约 160ms                     | 点击即时生效，无完成动画后才执行的等待               |
| 档案切换         | 正文约 500ms，英文标识约 600ms，立绘约 650ms | 以档案 ID 更新场景；下一次选择直接替换当前内容       |
| 初始／精英化立绘 | 立绘使用同一入场动效                         | 文本不随立绘版本变化，切换档案复位为初始图           |
| 检索与阅读浮层   | 约 250ms 的位移与淡入                        | 原生 dialog 限制背景操作，关闭后恢复先前焦点         |
| 目录展开         | 约 250ms；离开延迟 700ms                     | 固定展开或内部存在键盘焦点时不自动关闭；触屏点击切换 |
| 界面显隐         | 约 300ms 淡出                                | 隐藏元素停止接收指针事件，恢复按钮及 Esc 可重新显示  |
| 检索卡片         | 悬停图像约 250ms 缩放，预览图约 300ms 入场   | 鼠标或键盘焦点仅预览；点击才改变档案和阅读足迹       |

正文保持稳定，不随鼠标倾斜。主立绘容器使用有限幅度倾斜，背景剪影和大字营造层次；装饰不覆盖阅读内容。动画由 `terminal.css` 管理，场景变更不建立播放队列。

## 专属主题场景

`VisualScene` 以十二组条目绑定提供八组效果，由 `visual-profiles.ts` 显式登记：源石晶面、雪境山线、深海波纹、莱茵轨道、萨科塔光环、巴别塔记忆残片、耀骑士光束和夕的水墨山形。匹配条目 ID、名称或来源页标题，同源的其他资料也可能沿用效果。来源参考登记在配置中；效果是本站的视觉表达，不作为世界设定事实。

主题入场在 900ms 内结束，指针移动合并到单个 RAF，不建立常驻粒子循环。阅读时降低视觉强度；页面隐藏、小屏、触屏和减少动态效果状态下停止指针响应。属性面板的有限宽度过渡也响应减少动态效果偏好。

## 鼠标与浮窗

- `usePointerEffects` 合并实际鼠标移动到单个 RAF：倾斜计算上限 X 3.5°／Y 4°，按钮吸附每轴 2.5px；档案立绘进一步缩小倾斜倍率。离开、失焦和卸载时清理样式，没有空闲运行的 RAF 循环。
- 点击反馈通过 Web Animations 播放约 420ms。同一目标重复点击取消旧动画；卸载或减少动态效果时取消未完成动画。
- 地图 `useFloatingPanel` 使用 pointer capture 拖动资料窗，并限制在视口 16px 内边距以内。抬起、取消、丢失 capture、失焦和卸载均释放；窗口尺寸变化后复位，手机不启用拖动。
- 地图浮窗方向键移动 16px，Shift 加速到 40px；Home、标题栏双击或复位按钮归位。资料主舞台的阅读框使用模态阅读布局，不继承地图拖窗操作。

## 地图节奏

| 场景               | 表现与时长                                            | 接管／结束                                     |
| ------------------ | ----------------------------------------------------- | ---------------------------------------------- |
| 地图总览入场／重播 | 地形波次升起、扫描、地名错时显现、远景推进，共 2.8 秒 | 跳过、选点、拖动或减少动态效果时结束           |
| 选择国家或城市     | 平滑运镜 1.35 秒，轻微抬升后收稳                      | 新选点从当前位置接续；拖动立即交还控制         |
| 地区定位           | 边界描绘 1.4 秒、双圈定位在 2.4 秒内结束              | 更换条目替换旧轨迹，不持续闪烁                 |
| 关联图层           | 三维曲线逐段出现，二维路径描边                        | 图层关闭时卸载                                 |
| 六站导览           | 每站 10 秒及当前章节进度                              | 手动操作暂停；页面隐藏暂停；继续时本章重新计时 |
| SVG 地图           | 地区展开、定位与路径描绘                              | 保留选择和轻量回退，不需要 WebGL               |

地图常量在 `src/lib/motion.ts` 集中维护，DOM／SVG 动效在 `src/motion.css`，悬浮地图组件在 `src/floating.css`。`TerraScene` 使用已有 React Three Fiber demand 帧循环；只在有限过渡和实际操作期间请求下一帧。描线几何与材质随节点释放。

三维地图离开后返回同一地理条目，会恢复本次页面会话中的镜头位置、目标和按视口比例调整的缩放。选择其他地点、重播或复位仍按对应操作定位；镜头快照不写入持久存储，刷新页面后重新开始。

## 减少动态效果与维护

站内偏好与系统 `prefers-reduced-motion` 取逻辑或。任一启用时停用 CSS 装饰、指针跟随和点击圈，地图直接定位；按钮、滚动、拖动和阅读仍然可用。`useMotion` 监听系统偏好实时变化。

页面进入后台时暂停 CSS 动画与自动导览；三维运动不会推进隐藏帧，恢复时限制异常大的帧差。计时器、指针事件与可见性监听在卸载时清理。

维护时检查快速连点、打开／关闭、键盘焦点、触屏、后台切换与减少动态效果。`tests/motion.test.ts` 和 `tests/floating.test.ts` 覆盖运动计算、边界与状态契约；它们不能替代浏览器视觉检查。`qa.html` 保留 WebGL 故障与系统减少动态效果的开发辅助入口，不进入生产构建。实际检查结论见 [VERIFICATION.md](VERIFICATION.md)。
