# 档案资料与美术来源

本页记录首版 64 条游戏档案及 122 张图片的来源流程。扩展资料库的原图缓存、WebP 变体、每条目美术清单与增量更新见 [PRTS 本地资料库](LIBRARY.md)，最新资源范围以 `public/assets/library/manifest.json` 为准。

首版精选目录包括 24 位干员、16 种敌人和 24 件道具；世界观条目沿用原站资料。资料核验时间为 2026 年 9 月 30 日。目录为构建时的本地快照，用户浏览时不会请求或抓取 PRTS。

## 资料依据

- 主资料库：[PRTS Wiki](https://prts.wiki/w/首页)。每个档案保留其对应条目链接和核验日期。
- 官方设定与作品：[明日方舟官方网站](https://ak.hypergryph.com/)。本项目是资料浏览工具，与官方及 PRTS 无隶属关系。
- 干员属性采用各档案注明的精英阶段、等级、潜能和加成条件；敌人属性区分通常数据、级别及战斗阶段。战斗数值会随游戏更新变化，应以来源页和游戏内显示为准。
- 正文使用编辑摘要；重要剧情通过剧透设置控制。相同人物的干员档案与敌人档案使用不同稳定 ID，异格同样独立建档。

## 本地美术

`src/data/catalogue-assets.json` 与公开副本 `public/assets/catalogue/sources.json` 逐项记录稳定 ID、素材类型、来源页面、文件页、原图 URL、实际下载 URL、源站更新时间、核验日期、字节数、像素尺寸及本地 SHA-256。`focalPoint` 是展示建议，不会修改原始美术。

所有素材均由 PRTS 的 MediaWiki `imageinfo` 接口解析真实文件地址，再从 `media.prts.wiki` 下载。不推算文件哈希路径、不使用生成图片代替游戏素材。超过 1200 像素的立绘使用 PRTS 提供的 1200 像素缩略图；较小图片使用其原始尺寸。

| 分类                     | 素材类型                         | 说明                                                                                         |
| ------------------------ | -------------------------------- | -------------------------------------------------------------------------------------------- |
| 24 位干员                | `portrait`、`elite`、`thumbnail` | 初始立绘、精英化二立绘与头像；阿米娅使用术师形态                                             |
| 16 种敌人                | `enemy`                          | 对应页面引用的剧情立绘，或游戏图鉴头像                                                       |
| 具有剧情立绘的 10 种敌人 | `thumbnail`                      | 搜索结果使用独立的小头像，避免下载整张立绘                                                   |
| 24 件道具                | `item`                           | 道具原始图标；其中模组数据块、游击队员徽章、沃伦姆德搜查令、蚀刻弹弹壳使用源站提供的带框图标 |

敌人剧情立绘的文件名在导入脚本中明确列出，来自对应敌人页的图片列表。没有独立剧情立绘的敌人保留源站图鉴头像，不人为放大图片文件或补造图像；界面在显示时应保留这些图标的原始清晰度限制。

美术、人物、标志及相关商标属于鹰角网络及关联权利人。PRTS 托管这些游戏素材并不代表素材获得开放许可；清单中的来源信息用于溯源与署名，不授予再许可。发布者应自行遵守来源站条款和适用的权利人要求。

## 更新与校验

在项目根目录运行：

```sh
node scripts/import-catalogue-assets.mjs
node scripts/import-catalogue-assets.mjs --verify
```

普通导入会验证本地 SHA-256 并跳过完好的已有文件，分批导入并在批次完成后保存清单；中断后可以直接重新执行。`--verify` 完全离线，检查全部 64 个条目的必要美术、重复 ID/类型、来源信息、尺寸、字节数和文件校验和；失败时返回非零退出状态。

定向补充或重新核验：

```sh
node scripts/import-catalogue-assets.mjs --only=operator-amiya,operator-kaltsit
node scripts/import-catalogue-assets.mjs --only=enemy-patriot --refresh
```

`--refresh` 重新查询远端并下载指定范围的图片；未指定范围时更新整个精选清单。核验日期默认采用运行当天的 UTC 日期，可用 `CATALOGUE_CHECKED_AT=YYYY-MM-DD` 显式指定编辑日期。远程失败不会删除旧文件，导入器会输出失败项并返回非零退出状态。网络环境需允许 HTTPS 访问 `prts.wiki` 和 `media.prts.wiki`；Windows 上使用系统 `curl.exe` 并限定 IPv4，以避开不通的 IPv6 CDN 路由。

增加条目时，同步更新资料目录和导入脚本里的精选 ID/名称表。UI 使用 `catalogueAssetFor(id, kind)` 和 `catalogueAssetUrl(asset)`，不要硬编码远端地址。列表优先加载 `thumbnail`，没有独立缩略图的敌人与道具使用其 `enemy`／`item` 资源；完整立绘只在阅读相应档案时加载。
